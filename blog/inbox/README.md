# Customer story inbox

Have a real, happy customer moment? Drop it here and the robot writer turns it into a blog post the next time it runs.

## How to add one

1. Copy `TEMPLATE.md` (in this folder) to a new file, for example `2026-10-garcia-family.md`.
2. Fill it in with plain notes. It doesn't need to be polished, that's the robot's job.
3. Make sure the customer said yes to being featured. **The robot skips any story without `Customer permission: yes`.**

Stories are always used before topic ideas. After a story is used, it moves to `used/` so it's never written twice.

## Why only real stories?

The AI is told never to invent customers, quotes, prices or reviews. Made-up testimonials are against FTC rules, and AI search tools trust businesses less when they find them. Real stories are what make this blog work.
