# Button

Pill buttons: one lime primary, an outlined secondary and an underlined text link.

- `sw-btn sw-btn--primary`: `lime-voltage` fill with `forest-ink` label. Use one per section.
- `sw-btn sw-btn--outline`: `paper` fill with a 1px `forest-ink` ring, for secondary actions.
- `sw-btn sw-btn--link`: underlined `forest-ink` text, paired beside the primary.

On forest sections, wrap them in `sw-on-dark` so the link and outline turn `paper`. Labels are verbs in `label` style. The consumer provides the label and the link or handler.
