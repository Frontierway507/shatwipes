# Card

There are two cards: a light product card and a dark section card for the big sell.

- `sw-card`: `paper` with a `ring-subtle` hairline and `radius-card` corners. It holds `sw-card__title` (Inter 700 in `forest-ink`), `sw-card__body` (in `slate`) and a price tag.
- `sw-dark-card`: `forest-ink` with `radius-card-lg` corners and `space-40` padding. The headline is `lime-voltage` Inter 700 at 36px and the body is `paper`. It has one primary button.

The consumer provides the content.
