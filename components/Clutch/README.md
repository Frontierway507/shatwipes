# Clutch

The purse pack: a slim 12-wipe pouch in `obsidian` with a `lime-voltage` wordmark, built as `sw-pack sw-pack--clutch`.

It uses the same parts as every pack (`__flap`, `__mark`, `__sub`, `__line`, `__pills`) at a tighter size, with `radius-badge` corners instead of `radius-card-lg`. Keep the tagline to one short line and show two claim pills at most. Real dimensions are in the Sizing section. The consumer provides the tagline and claims.
